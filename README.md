AI & Machine Learning — Assignment 1 Submission

Author: Antony

Overview: This project contains solutions for Module 1 coursework divided into two components:

Practical Programming (exercise_1.py): Conceptual foundations covering AI vs. traditional programming, AI taxonomy (Narrow, General, Super AI; 
                                        Reactive to Theory of Mind), ML paradigms (Supervised, Unsupervised, Reinforcement Learning), and model behavior
                                        (overfitting, rewards, dimensionality reduction).

 Theory(exercise_2.py): Python implementation covering language fundamentals (immutability, scoping, lambda functions), exception handling patterns 
                       (try-except-else-finally), data structures (sets, tuples), and algorithmic functions (prime testing, palindrome verification,
                       Fibonacci generation, and number manipulation)
